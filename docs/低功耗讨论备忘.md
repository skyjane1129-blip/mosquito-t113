# Mosquito 项目低功耗讨论备忘

记录日期：2026-08-18

## 当前结论

- 现有 T113-S3 PCB 可以先从软件层面降低功耗，包括关闭摄像头和 Air780EG、减少无用外设、启用 CPUFreq/CPUIdle，以及验证 Linux suspend-to-RAM 和 RTC 定时唤醒。
- 当前内核已经启用 `CONFIG_SUSPEND` 和 `CONFIG_PM_SLEEP`，但 CPUFreq、CPUIdle 和完整 RTC 唤醒能力尚未启用或验证。
- 纯软件优化可以降低运行和休眠功耗，但无法在整机完全断电后自行定时重新上电。
- 若后续目标是长期电池或太阳能野外运行，下一版 PCB 可考虑增加超低功耗 MCU/RTC 电源管家，控制 T113 主电源，并承担定时唤醒、硬件看门狗、电池检测和异常强制重启。
- 电源管家设计时需要重点处理 Linux 安全关机、总电源使能、电源时序和 UART/I²C/GPIO 倒灌。

## 后续处理顺序

1. 测量当前空闲、关摄像头、关 4G、拍照和上传状态的实际功耗。
2. 开启并验证 CPUFreq、CPUIdle。
3. 补全 RTC 驱动并测试 `freeze`、`mem` 及定时唤醒。
4. 验证多次休眠唤醒后的 TF 卡、USB 摄像头、Air780EG 和网络恢复。
5. 根据实测结果决定下一版 PCB 是否增加独立电源管家。
