## 4. 明确授权边界

在用户分别明确批准前，不执行以下操作：

- 购买或创建收费云资源；
- 写入真实账号、口令、设备密钥、AccessKey 或客户数据；
- 修改客户 DNS、域名、备案或公网防火墙；
- 修改现有系统启动行为，或把 root、无认证 ADB 自动打开；
- 运行 Tina 完整镜像构建、`pack`、烧录或覆盖现有镜像；
- Git 提交、推送、创建 PR、合并或发布。

## 5. 已知生命周期风险

当前客户端和云端按既定计划使用 .NET 8。[微软官方支持策略](https://dotnet.microsoft.com/en-us/platform/support/policy)显示 .NET 8 的维护支持截止 2026-11-10；生产交付前应评估并优先迁移到仍处于长期支持期的 .NET 版本，重新执行构建、客户端启动和全链路回归。
