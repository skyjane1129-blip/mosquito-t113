# 蚊卵检测模型 r1（2026-09-15）

`mosquito_egg_r1.pt` —— YOLO26s，公开数据预训练 + 手机拍摄的杯内滤纸图微调。
类别：0 = mosquito，1 = egg。**这一版只对 egg 做过评测，mosquito 未评测，不要用它数蚊子。**

## 环境

```
pip install ultralytics>=8.4 opencv-python numpy
```

## 用法（必须用 count.py，不要直接 yolo predict）

```
python count.py mosquito_egg_r1.pt <图片或文件夹> --out 结果目录 --egg-tile 256 --conf 0.25
```

输出：每张图标注好的 jpg + `_计数.csv`（每图蚊卵数与合计）。

## 为什么不能直接 yolo predict

卵在 4160 宽的手机图里只有约 20 像素。模型是在 640 输入、卵约 40 像素的尺度上训的，
所以 `count.py` 会把整图切成小块再送模型（`--egg-tile 256` 是以 3264 宽为基准的切片边长，
会按图宽自动缩放），并在切片重叠区做去重。整图直接送模型等于把卵缩到几个像素，检不出来。

## 参数

- `--egg-tile 256`：手机 4160 宽图实测最优。固定相机 3264 宽图用 448。
- `--conf 0.25`：默认。3 张测试图上 0.25 计数偏多约 7%，0.35 接近 1:1；想保守就用 0.35。

## 已知精度（3 张测试图，仅供参考，样本很少）

框级别精确率 0.845、召回 0.840；整图计数误差约 10%。
主要误检来源：塑料杯壁的划痕和纤维。杯壁区域的框可以忽略。
