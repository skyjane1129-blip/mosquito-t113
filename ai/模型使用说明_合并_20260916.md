# 蚊子 + 蚊卵 合并识别（2026-09-16）

把两套模型拼成一条流水线：**蚊子用两级模型（YOLO11m 检测 + YOLO11s-cls 分类挡误报），蚊卵用切片模型（YOLO26s）。**
两边各取所长：两级方案在实拍上蚊子无误报；切片方案对 20px 的卵和密集卵团召回高得多。

## 环境（只做一次）

```
pip install ultralytics opencv-python numpy pillow
```

## 用法

```
python detect_combined.py <图片或目录>              结果写到 <目录>\识别结果\ + 汇总.csv
python detect_combined.py <目录> --out D:\out
python detect_combined.py <目录> --no-label         结果图只画框不写字
```

产品相机 MQ-SH-001（3264×2448）直接用默认参数。手机拍的 4160 宽图加 `--egg-tile 256`。

## 阈值

| 参数 | 默认 | 说明 |
|---|---|---|
| `--cls-thr` | 0.7 | 蚊子分类器阈值。误报多调到 0.8~0.9，漏得多降到 0.5 |
| `--det-conf` | 0.15 | 蚊子候选阈值，故意放低让分类器筛，一般不动 |
| `--egg-conf` | 0.25 | 卵阈值。杯壁杂质被当成卵就调到 0.35 |
| `--egg-tile` | 224 | 卵切片边长（以 3264 宽为基准，按图宽自动缩放）。手机图 256 |

## 结果图颜色

蓝框 = 蚊子（标签是分类器概率）；灰框 = YOLO 框到但分类器排除的候选（`--no-reject` 可不画）；红框 = 卵。

## 已知水平（样本很少，仅供参考）

- 蚊子（同事验证）：实拍无误报；约每 7 只漏 2 只；摇蚊会被当成蚊子。
- 卵：手机图 3 张独立测试计数 79/75；产品相机唯一的未见样本召回 88%（r2 对 img001）。
  主要误差：**塑料杯壁划痕/污点被当成卵**（每图约 10 个）、密集糊团内部漏检。

## 为什么卵不能用整图推理

卵在 3264 宽的图里只有约 20 像素。整图缩到 1280 送模型，卵只剩 8 像素，检不出来。
所以切成 224px 小片、放大到 640 再推理，然后在全图坐标上跨片去重（切片有 25% 重叠，
同一颗卵会被相邻两片各检出一次；去重只在不同切片的框之间做，同片内的重叠框是两颗真卵）。
